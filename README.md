# 🌸 SCENT HAVEN  
## Perfume Ordering System

---

## 📖 Project Description
Scent Haven is a web-based **Perfume Ordering System** developed using **PHP and MySQL**.  
The system allows users to browse perfumes, filter them by fragrance type and price, add items to a cart, and place orders online.

This project is developed for **academic purposes** and demonstrates how an online ordering system works using web technologies.

---

## 🎯 Objectives
- To design and develop a perfume ordering web application
- To implement database connectivity using PHP and MySQL
- To demonstrate CRUD operations
- To allow users to browse and order products online
- To create a clean and user-friendly interface

---

---

## ✨ Features
- Browse available perfumes
- Search perfumes by name or description
- Filter by fragrance family (Floral, Fresh, Woody, Oriental, Gourmand)
- Filter by price range
- Availability status display
- Add to cart functionality
- Order placement system
- Landing page with hero image
